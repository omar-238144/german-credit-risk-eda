# German Credit Risk - Exploratory Data Analysis (EDA)

This repository contains an advanced Exploratory Data Analysis (EDA) performed on the German Credit Risk dataset as part of our Machine Learning coursework.

## 📊 Project Highlights & Workflow
* **Data Inspection**: Checked data structure, missing values, and descriptive statistics.
* **Univariate Analysis**: Visualized distributions of numerical features (`Credit amount`, `Duration`, `Age`) and categorical attributes (`Housing`, `Purpose`, `Saving accounts`) with custom analytical side-notes.
* **Target Analysis (`Risk`)**: Explored class balance and distribution between good and bad credit risks.
* **Bivariate Analysis**: Evaluated feature relationships against the target variable using box plots and count plots.
* **Correlation Analysis**: Generated a correlation heatmap to detect multicollinearity among numerical features.

## 🛠️ Technologies Used
* Python
* Jupyter Notebook (`.ipynb`)
* Pandas & NumPy (Data manipulation)
* Seaborn & Matplotlib (Advanced data visualization with custom styling)
